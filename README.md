# Hebrew Text Converter - ממיר טקסט עברי

כלי Python להמרת טקסט שכתבת בעברית אבל באותיות אנגליות (כמו LANGOVER) לטקסט עברי אמיתי.

## תכונות

- המרה אוטומטית של טקסט עברי באותיות אנגליות לעברית אמיתית
- שמירה על אותיות רישיות (CAPS LOCK) כפי שהן
- הפעלה באמצעות מקשי קיצור גלובליים
- עובד בכל האפליקציות במחשב

## התקנה

1. התקן את התלויות הנדרשות:
```bash
pip install -r requirements.txt
```

## הפעלה

הרץ את הסקריפט:
```bash
python hebrew_converter.py
```

הסקריפט יתחיל לרוץ ברקע וימתין למקשי הקיצור.

## אופן השימוש

1. כתוב טקסט בעברית באותיות אנגליות (לדוגמה: `vcs,u ohc vcsv,u`)
2. סמן את הטקסט עם העכבר או המקלדת
3. לחץ על **Ctrl+1** להמרה
4. הטקסט יוחלף אוטומטית לעברית אמיתית (`שלום, מה שלומך`)

## מקשי קיצור

- **Ctrl+1** - המרת הטקסט המסומן
- **F12** - יציאה מהאפליקציה

## דוגמאות המרה

| טקסט באנגלית | טקסט בעברית |
|---------------|--------------|
| `vcs,u` | `שלום` |
| `ohc vcsv,u` | `מה שלומך` |
| `vcs,u ohc vcsv,u` | `שלום, מה שלומך` |
| `HELLO vcs,u` | `HELLO שלום` |

## הערות חשובות

- האפליקציה עובדת ברקע - אל תסגור את חלון הטרמינל
- אותיות רישיות (CAPS LOCK) נשארות כפי שהן
- האפליקציה עובדת בכל התוכנות במחשב
- במקרה של בעיות הרשאות, ודא שהתוכנה יכולה לגשת למקלדת וללוח העריכה

## דרישות מערכת

- Python 3.6+
- Windows/macOS/Linux
- הרשאות גישה למקלדת וללוח העריכה
