# Hebrew Text Converter Advanced - ממיר טקסט עברי מתקדם

כלי Python מתקדם להמרת טקסט שכתבת בעברית אבל באותיות אנגליות (כמו LANGOVER) לטקסט עברי אמיתי, עם אפשרות להגדרת מקשי קיצור מותאמים אישית.

## תכונות חדשות ✨

### 🎛️ הגדרת מקשי קיצור מותאמים
- **הגדרה גמישה**: בחר כל מקש קיצור שתרצה להמרה וליציאה
- **ממשק ידידותי**: חלון הגדרות נוח עם אפשרות להאזין למקשים
- **מגוון אפשרויות**: תמיכה במקשי F1-F12, Ctrl, Alt, Shift וצירופים
- **שמירה אוטומטית**: ההגדרות נשמרות אוטומטית וטעונות בהפעלה הבאה

### ⚙️ הגדרות מתקדמות
- **זיהוי אוטומטי של עברית**: אפשרות לכבות/להדליק
- **דילוג על פקודות טרמינל**: אפשרות לכבות/להדליק
- **שמירת אותיות רישיות**: אפשרות לכבות/להדליק
- **גודל היסטוריה**: הגדר כמה המרות לשמור
- **הגדרות לוגים**: רמת לוגים ושמירה לקובץ

### 🖥️ ממשק משתמש משופר
- **חלון הגדרות מתקדם**: גישה לכל ההגדרות במקום אחד
- **היסטוריית המרות**: צפייה בכל ההמרות שביצעת
- **סטטוס מפורט**: מידע על מצב התוכנה והגדרות נוכחיות
- **אייקון במגש המערכת**: גישה מהירה להגדרות ויציאה

## התקנה

1. התקן את התלויות הנדרשות:
```bash
pip install -r requirements.txt
```

## הפעלה

### גרסה בסיסית (מקשי קיצור קבועים)
```bash
python hebrew_converter.py
```

### גרסה מתקדמת (מקשי קיצור מותאמים)
```bash
python hebrew_converter_advanced.py
```

### גרסה עם אייקון במגש
```bash
python hebrew_converter_tray.py
```

## אופן השימוש

### המרת טקסט
1. כתוב טקסט בעברית באותיות אנגליות (לדוגמה: `vcs,u ohc vcsv,u`)
2. סמן את הטקסט עם העכבר או המקלדת
3. לחץ על מקש הקיצור המוגדר (ברירת מחדל: `Ctrl+Alt+H`)
4. הטקסט יוחלף אוטומטית לעברית אמיתית (`שלום, מה שלומך`)

### הגדרת מקשי קיצור (גרסה מתקדמת)
1. לחץ ימין על האייקון במגש המערכת
2. בחר "הגדרות"
3. לחץ על "הגדר מקשי קיצור"
4. בחר מקשי קיצור חדשים או לחץ על "האזן" להקלדה
5. לחץ "שמור הגדרות"

## מקשי קיצור ברירת מחדל

### גרסה בסיסית
- **Alt+H** - המרת הטקסט המסומן
- **Ctrl+Shift+Q** או **Alt+Q** - יציאה מהאפליקציה

### גרסה מתקדמת
- **Ctrl+Alt+H** - המרת הטקסט המסומן
- **Ctrl+Shift+Q** או **Alt+Q** - יציאה מהאפליקציה

### מקשי קיצור זמינים להגדרה
- מקשי F1-F12 (עם או בלי Ctrl/Alt/Shift)
- צירופי מקשים עם Ctrl, Alt, Shift
- מקשי קיצור מותאמים אישית

## דוגמאות המרה

| טקסט באנגלית | טקסט בעברית |
|---------------|--------------|
| `vcs,u` | `שלום` |
| `ohc vcsv,u` | `מה שלומך` |
| `vcs,u ohc vcsv,u` | `שלום, מה שלומך` |
| `HELLO vcs,u` | `HELLO שלום` |

## קבצי הגדרות

### `hebrew_converter_settings.json`
קובץ הגדרות JSON שמכיל:
- מקשי קיצור מותאמים
- הגדרות המרה
- הגדרות ממשק משתמש
- הגדרות לוגים

### דוגמה לקובץ הגדרות:
```json
{
  "hotkeys": {
    "convert": "<ctrl>+<alt>+h",
    "exit": ["<ctrl>+<shift>+q", "<alt>+q"]
  },
  "conversion": {
    "auto_detect_hebrew": true,
    "skip_terminal_commands": true,
    "preserve_caps": true
  },
  "ui": {
    "show_splash": true,
    "splash_duration": 5,
    "history_size": 50
  },
  "logging": {
    "level": "INFO",
    "log_to_file": true
  }
}
```

## פתרון בעיות

### בעיות הרשאות
- **Windows**: ודא שהתוכנה יכולה לגשת למקלדת
- **macOS**: אפשר גישה ב-Accessibility settings
- **Linux**: ודא שהמשתמש נמצא בקבוצת input

### בעיות מקשי קיצור
- ודא שמקש הקיצור לא תפוס על ידי תוכנה אחרת
- נסה מקש קיצור אחר אם הנוכחי לא עובד
- בדוק את קובץ ההגדרות `hebrew_converter_settings.json`

### בעיות המרה
- ודא שהטקסט מסומן לפני לחיצה על מקש הקיצור
- בדוק שהטקסט לא מכיל רק אותיות עבריות
- בדוק את הלוגים למידע נוסף
